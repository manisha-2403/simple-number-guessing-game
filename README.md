# Number Guessing Game

A beginner-friendly command-line number guessing game developed using Python.

## How the Game Works

The computer randomly selects a number between 1 and 100.

The player tries to guess the number.

After each guess, the program tells the player whether the guess is:

* Too high
* Too low
* Correct

The program also counts the number of attempts.

## Features

* Random number generation
* User input
* High/low hints
* Attempt counter
* Input validation
* Limited attempts
* Game-over condition

## Technologies Used

* Python
* Python IDLE
* Random module

## How to Run

1. Download or clone the repository.
2. Open `guessing_game.py` using Python IDLE.
3. Press `F5` or select Run → Run Module.
4. Enter a number between 1 and 100.
5. Continue guessing until you find the correct number.
